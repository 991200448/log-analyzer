Log Analyzer 日志分析工具
一款纯前端离线日志解析可视化工具，开箱即用，无需后端、无需部署，本地加载 .log/.txt 日志文件，支持多维度统计、图表可视化、Trace 链路追踪、异常堆栈聚合。
项目简介
本工具基于原生 HTML + CSS + JavaScript 实现，使用 Web Worker 分片大文件解析，避免页面卡顿；内置暗黑 / 浅色双主题，完整覆盖日志排查常用能力：
本地离线解析，日志不会上传任何服务器，数据安全
超大日志分片读取，支持 GB 级日志文件
多维度图表：错误分布折线图、错误占比饼图、ERROR 时间趋势图
TraceId 全链路检索、线程耗时统计、异常堆栈自动聚合
日志级别筛选、关键词搜索、时间范围过滤、重复日志合并
原始日志弹窗检索、高亮匹配、上下翻页定位
分页展示、一键跳转原文、导出底层能力预留
预览截图
可自行截取页面补充到此处，包含上传区、数据看板、图表、Trace 追踪、异常聚合页面
功能特性
1. 文件上传与解析
支持点击选择 / 拖拽上传 .log、.txt 文本日志
Web Worker 分片异步解析，大文件不阻塞页面
可设置起始时间过滤，只解析指定时间之后日志
「查看原文」独立弹窗，完整加载原始日志，支持检索高亮
2. 日志基础筛选
日志级别快速筛选：ALL / DEBUG / INFO / WARN / ERROR
全局关键词模糊搜索（消息、类名、TraceId）
自动合并重复日志，统计重复次数、时间区间、线程数
分页展示，自定义每页展示条数（50/100/200/500）
3. 可视化看板（多标签页）
折线图：ERROR 错误类型出现次数排行，hover 查看详情，点击跳转日志
饼状图：各类错误占比甜甜圈图，图例悬浮高亮，快速定位高频报错
时间趋势：按小时统计 ERROR 数量，直观查看报错爆发时段
TraceId 追踪：自动分组所有 TraceId，下拉快速检索，展示完整调用链
线程耗时：按 Trace 统计整条链路总耗时，表格排序，耗时色块可视化
异常聚合：自动识别 Exception/Error 堆栈，按 TraceId 分组折叠查看完整堆栈
4. 便捷交互
Ctrl + 点击日志条目：自动填充时间、搜索原文定位当前日志
原始日志弹窗检索：支持回车上下切换匹配结果，关键词高亮
暗黑 / 浅色主题一键切换，主题配置本地持久化
图表自适应窗口大小，hover 悬浮提示框展示完整报错信息
5. 安全优势
纯前端离线运行，所有文件读取仅在浏览器本地完成
无网络请求、无日志上传、无第三方接口依赖
日志数据仅保存在浏览器内存，刷新页面即清空
